# Signa — описание проекта для жюри ADMIT HACKATHON

**Трек:** MOTION — камера вместо джойстика
**Проект:** Signa — «Твои руки говорят. Теперь их услышит каждый.»

## Что мы создали

Signa — веб-приложение, которое превращает обычную веб-камеру в переводчик жестов в речь. Человек показывает жест перед камерой. Signa распознаёт его в реальном времени, крупно выводит фразу на экран и произносит её вслух. Разговор сохраняется как чат, и собеседник может ответить текстом или голосом. Получается двусторонний диалог, а не демонстрация технологии.

Ничего не нужно устанавливать: открыть ссылку → **Start talking** → разрешить камеру → показать жест.

## Какую проблему решаем

Людям, которые общаются руками (глухим и слабослышащим, невербальным, пациентам после инсульта или интубации), трудно объясниться с тем, кто не знает жестового языка. Даже простые «Мне больно», «Помогите», «Где туалет?», «Хочу пить» превращаются в угадайку. Signa даёт этим фразам голос.

## Как это работает

```
Камера → 21 точка руки (MediaPipe) → НАШИ признаки → НАШИ правила → временная валидация
      → фраза → текст на экране + синтез речи → история разговора
```

1. **MediaPipe HandLandmarker** служит только датчиком: он даёт координаты 21 сустава. Решение о том, какой это жест, принимает наш код.
2. **Признаки** (`src/vision/features.js`): степень сгибания каждого пальца (сумма углов в суставах + отношение расстояний кончик/костяшка до запястья), вытянутость большого пальца, направление кисти и пальцев, раздвинутость пальцев, касания кончиков, ориентация ладони (векторное произведение + handedness), размер руки и выход за кадр.
3. **Правила** (`src/vision/gestureRules.js`): каждое правило возвращает мягкую оценку 0..1, конкретную подсказку и приоритет.
4. **Классификатор** (`gestureClassifier.js`): взвешенное совпадение (Match %). Жест принимается, только если совпадение ≥ 80 % и ни одно правило не нарушено грубо.
5. **Динамика** (`motion.js`): взмах (подсчёт штрихов зигзага), покачивание пальцем, движение вниз, круг (накопленный угол). Всё измеряется в «длинах ладони», поэтому не зависит от расстояния до камеры. Резкие скачки трекинга не считаются движением.
6. **Временная валидация** (`gestureEngine.js`): статичный жест нужно удерживать неподвижно ~0,65 с (≈20 кадров). После распознавания действует cooldown 1,3 с, а то же слово повторится, только если рука сменила жест. Одно слово не звучит 20 раз подряд.

Жесты описаны **декларативно** в `src/data/gestures.js`, без if/else. Новый жест или язык добавляется одним объектом, и иконка руки для него рисуется автоматически из описания.

## Какие жесты распознаются (19)

**Статичные (15):** MY NAME IS, YES 👍, NO 👎, HELP ✊, I LOVE YOU 🤟, PLEASE 👌, STOP ✋, PAIN (когти), EAT (щепоть), DRINK 🤙, MORE ✌️, BATHROOM (мизинец), HOW? (указательный вбок), WHAT? (W), WHEN? (L).
**Динамичные (4):** HELLO (взмах открытой ладонью), THANK YOU (ладонь вниз от подбородка), SORRY (круг кулаком), WHERE? (покачать указательным пальцем).

Каждый жест вызывает своё действие: показать фразу, озвучить её и добавить в историю. В режиме тренировки жест засчитывается и открывается следующий.

## Как реализован режим «Ошибка»

Приложение никогда не пишет просто «жест не распознан». Каждое правило умеет объяснить, почему не выполнено, а движок сообщает проблемы **по приоритету**:

1. **Кадр:** руки не видно / две руки / рука обрезана краем / слишком далеко / слишком близко → «Покажи только одну руку», «Поднеси руку ближе к камере», «Подними руку выше — она обрезана снизу».
2. **Ориентация:** «Разверни ладонь к камере», «Направь большой палец вниз», «Поверни руку боком».
3. **Конфигурация пальцев:** «Согни средний палец», «Выпрями безымянный палец», «Прижми большой палец».
4. **Детали:** «Раздвинь указательный палец и средний палец», «Коснись большим пальцем кончика указательного пальца».
5. **Удержание и движение:** «Держи руку неподвижно», «Держи… 0.3 с», «Теперь помаши из стороны в сторону», «Сделай круг больше».

Дополнительно:
- **Палец, который нужно исправить, подсвечивается красным** прямо на видео, правильные пальцы зелёным. Под подсказкой есть чек-лист пальцев.
- В тренировке система знает цель и говорит, на что похож показанный жест: «Цель: НЕТ → Направь большой палец вниз. Это похоже на ДА.»
- В разговоре, когда рука замерла, система определяет ближайший жест и подсказывает альтернативы: «WHERE?: теперь движение. Или: MORE — выпрями средний палец».
- Подсказки сглажены по времени (≈260 мс), поэтому не мигают.

## В чём собственная логика команды

- Свой набор признаков руки и своя калибровка порогов. Пороги сначала подобрали на синтетической 3D-модели руки, потом **перекалибровали на реальных данных MediaPipe**. Реальные фото теперь входят в регрессионные тесты.
- Свой rule-based классификатор с весами и «жёстким минимумом» по каждому правилу.
- Свой детектор динамических жестов и защита от скачков трекинга.
- Своя временная валидация (hold + стабильность + cooldown + release).
- Своя система диагностики ошибок с приоритетами и локализованными (EN/RU/KZ) подсказками с правильными падежами.
- Готовые демо «gesture recognition» и модель MediaPipe Gesture Recognizer **не используются**.
- 50 автотестов (`npm test`): все 19 жестов, сценарии Error Mode, тайминги, движения, реальные ладони.

## Технологии

React 18, Vite 6, JavaScript · MediaPipe Tasks Vision HandLandmarker (WASM + WebGL, fallback на CPU) · Web Speech API (speechSynthesis, опционально SpeechRecognition) · getUserMedia · Canvas 2D · Web Audio · CSS · node:test. Бэкенда нет.

## Бонусные функции (реализованы)

- **Режим тренировки:** выбор жеста, инструкция, живая подсказка, «✓ Отлично!», автопереход к следующему жесту без мыши, прогресс «Выучено жестов: N / 19» (сохраняется локально).
- **История разговора:** чат, повтор каждой фразы 🔊, ответ собеседника текстом или голосом.
- **3 языка:** English, Русский, Қазақша (интерфейс, подсказки, фразы, озвучка).
- **Мобильная версия:** портретная раскладка, фронтальная камера.
- **Доступность:** крупный текст, высокий контраст, визуальные и звуковые уведомления, поддержка reduced-motion.
- **Визуальные эффекты:** светящийся контур и скелет руки, кольцо прогресса удержания, вспышка при распознавании.
- **Панель разработчика:** «живые» признаки, которые видят правила. Наглядно показывает, что распознавание — наша логика, а не чёрный ящик.

## Приватность

Видео обрабатывается локально в браузере и никуда не отправляется. Бэкенда нет. При первом запуске браузер скачивает публичный файл модели MediaPipe (~8 МБ). Опциональный голосовой ответ собеседника (кнопка 🎙) использует распознавание речи браузера; в Chrome это облачный сервис, поэтому функция включается только по нажатию.

## Честные ограничения

Это прототип словаря из 19 одноручных жестов, а не полноценный жестовый язык. PAIN (когти) и EAT (щепоть) распознаются хуже остальных из-за перекрытия пальцев. Качество голоса зависит от голосов ОС: если казахского голоса нет, текст читает русский голос.
